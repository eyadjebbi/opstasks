# Run OpsTasks on Minikube

Start Minikube and enable its Nginx Ingress controller:

```bash
minikube start
minikube addons enable ingress
```

Build both application images directly inside Minikube. This is required because
the deployments use `imagePullPolicy: Never` for the local images:

```bash
minikube image build -t opstasks-backend:latest ./backend
minikube image build -t opstasks-frontend:latest ./frontend
```

Apply all resources with Kustomize and wait for the deployments:

```bash
kubectl apply -k infra/k8s
kubectl rollout status deployment/postgres -n demo-app --timeout=120s
kubectl rollout status deployment/backend -n demo-app --timeout=120s
kubectl rollout status deployment/frontend -n demo-app --timeout=120s
```

Add the Ingress hostname to `/etc/hosts`:

```bash
echo "$(minikube ip) opstasks.local" | sudo tee -a /etc/hosts
```

Open <http://opstasks.local>. If the host cannot reach the Minikube IP directly
(common with some drivers), keep `minikube tunnel` running in another terminal.

The Secret generated by `kustomization.yaml` contains development-only Minikube
credentials. Replace those values before using these manifests elsewhere.
